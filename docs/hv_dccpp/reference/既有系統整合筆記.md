## 系統概況
- Tkinter 桌面 GUI + tkintermapview（Google 衛星圖），預設中心 (23.702732, 120.419333) 雲林斗六。
- 流程：地圖點 3–10 個角點 → `finish_boundary` → `preview_paths` → `export_waypoints`。
- 座標：對外一律 WGS84 十進位度的 `Tuple[float, float]` = **(lat, lon)**；內部用 111111 m/deg 平面近似；高度只有一個純量（相對 home，MAV_FRAME_GLOBAL_RELATIVE_ALT=3），每個航點同高度。
- 現有演算法：boustrophedon 掃描線（角度、間距、速度、yaw 速率），區域分割最多 4 塊（`RegionDivider.subdivide_rectangle/subdivide_polygon`），凹多邊形會被打穿；多機去衝突只有起飛延遲（LOITER_TIME）與 RTL 高度分層。
- 輸出：QGC WPL 110（tab 分隔 12 欄）`.waypoints` 檔，每區一檔 + `mission_briefing.txt`。指令：DO_SET_HOME(179)、DO_CHANGE_SPEED(178)、NAV_LOITER_TIME(19)、CONDITION_YAW(115)、NAV_WAYPOINT(16)、NAV_TAKEOFF(22)、RTL(20)。**假設多旋翼**：ArduPlane/QuadPlane 固定翼段會忽略 CONDITION_YAW；沒有 VTOL_TAKEOFF/VTOL_LAND；沒有相機觸發（206）。
- 已知缺陷（不要複製）：`waypoint_generator.py:165` 13 欄；DO_SET_HOME 用 (0,0,0)；任務中段插入 NAV_TAKEOFF 來設 RTL 高度。
- MQTT（`mqtt_client.py`，未接進 main_app）：broker localhost:1883，topic `drone/waypoints`，QoS 1；接受 `{"waypoints":[{"lat","lon"},...]}` / `{"waypoint":{...},"index","total"}` / `{"lat","lon"}`；**硬限制恰好 4 點**；paho-mqtt v1 回呼簽章（2.x 會壞）。無 drone-id、無 mission-id、無遙測。
- 無 MAVLink / 無 pymavlink / 無 DEM / 無 geofence / 無載具模型；`FlightDynamics` dataclass（min_turn_radius 等）是死碼，可拿來放機體參數。
- 依賴：Python 3.8+，tkintermapview、numpy（未真的 import）。無 shapely（但 A 的 requirements 註解為可選）。
