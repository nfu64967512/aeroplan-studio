# 修正：3D 模型滾轉時只有偏航、沒有滾轉 — 2026-10-22

使用者：「我發現 SITL 在做 roll 動作的時候，模型只有偏航沒有滾轉。」本機 vtol 分支、**未 commit**。

## 原因

`ui/widgets/cesium_templates/main.html` 的 `_updateUAVOne` 把 GLB 的方向校正**直接加進姿態角**：
`HPR(機鼻 + hOff, pitch + pOff, roll + rOff)`。這有兩個錯：

1. **校正是模型自己座標系下的固定旋轉，不能和姿態角相加。** Cesium 的 HPR 是 `qHeading·qPitch·qRoll`（先繞 x 滾轉、再繞 y 俯仰、
   最後繞 z 偏航）。VTOL 與多旋翼 GLB 的校正是 pOff = 90°（模型本身是躺著的）⇒ 加進去的 roll 是繞「已經俯仰 90° 的 x 軸」＝**垂直軸**轉
   ⇒ 滾轉畫出來是偏航（使用者看到的現象）。
2. **Cesium HPR 的機體軸不是我們的。** Cesium 的 HPR 在航向 0 時 x 軸朝**東**（滾轉繞東軸、俯仰繞負北軸），而我們每個 GLB 都是
   「航向 0 時機鼻朝北」校正出來的 ⇒ 偏移全 0 的固定翼（Barracuda）一直是**滾轉變俯仰、俯仰變滾轉**（只是不明顯沒人發現）。

## 修法

新函式 `_uavModelOrientation`：在校正後的機體座標（航向 0 時機鼻 +y 北、右翼 +x 東、機背 +z）照航空慣例轉，再乘上校正：
`q = ENU(pos)·Rz(−機鼻)·Rx(+pitch 機頭上仰)·Ry(+roll 右翼下沉)·HPR(hOff, pOff, rOff)`。
水平飛行（pitch＝roll＝0）時與舊寫法**完全相同**，既有的目視校正（機鼻對準航向）不變；只改模型的畫法，不影響任何飛控、相機或疊圖。
