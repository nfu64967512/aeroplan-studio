## 3. 接進 AeroPlan

3D 頁原本只看機種字串（`vt`）選模型、完全不知道哪一架是 Hero。現在：

- `main.html`：第四種模型 `hero`（`_HERO_MODEL_URI`、頁面常數 `_HERO_*` 0/0/0、scale 1；之後加了 `pioneer`，範本佔位改名
  `/*__AIRFRAME_MODELS__*/`、`_hero_model_js` 改為 `_airframe_models_js`）；逐架機體表 `_UAV_AIRFRAME`＋預設
  `_UAV_AIRFRAME_DEFAULT`；`setUavAirframes(map, dflt)`。只有 VTOL 會畫 Hero；四個模型旗標互斥（Hero 優先），
  模型檔與校正出自同一個 `modelKind`，中途換機體走既有的「機型變了就重建」路徑（舊校正的姿態樣本丟掉）。
  沒有 hero.glb ⇒ 畫通用 vtol.glb（不會拿 Hero 的校正去畫別的檔）。
- `CesiumMapWidget`：範本的機體模型那一行由 `_airframe_models_js` 填（Hero／Pioneer URI＋預設＋逐架）；`set_uav_airframes(mapping, default)`
  執行期指定（記在 widget 上，頁面重載後套回去；值 None ⇒ 回到設定檔那一架或預設）。不認得的值記 warning、當成通用。
- 設定（`config/settings.json` 的頂層 `model3d` 區塊）：`vtol_model`（'hero'｜''｜'pioneer'，程式預設 ''）、`uav_airframes`
  （{"sysid": 機體}）。**本機設定檔已設 `"vtol_model": "hero"`** ⇒ 這台電腦上所有 VTOL 預設畫 Hero。
  ⚠ 第一版放在 `map` 底下：舊版本（HEAD、field）的 `MapSettings(**...)` 遇到不認得的鍵丟 TypeError ⇒ map 以後所有區塊回預設
  （審查實測）。現在放自己的區塊（舊版本會跳過）；讀到 `map` 底下的舊鍵會搬過來，`map` 的未知鍵只警告鍵名、不再中斷。
- HARVEST：任務上傳（`record_release_schedule`，一般上傳與建圖上傳都經過）後，構型取自**這份計畫本身**
  （`hv.last_plan.plans[id_map[drone_id]].cls`）：A ⇒ pioneer、B ⇒ hero。指定記在 `_hv_airframe_sysids`：換一份計畫 ⇒
  新計畫沒有的那幾架取消（回到設定檔）；同一份計畫分批上傳 ⇒ 累加；重開／停 SITL ⇒ 全部取消（同一個 sysid 之後是另一架模擬機）。
  一般（非 HARVEST）任務上傳不動它：HIL 板的機體是那塊飛控的物理屬性。
- 探針：`tools/attitude_fidelity_probe.py` 認得 'hero'（PINNED 0/0/0）；`tools/cesium_fps_probe.py` 帶 Hero URI。

⚠ 程式預設刻意是 ''：姿態探針用預設設定隔離使用者設定，它的閘門（含「舊的角度相加寫法要被抓到」）是針對通用 vtol.glb 的
−90/90/180 校正；預設改成 'hero' 會讓探針畫 Hero（0/0/0 校正下舊寫法根本不會出錯）⇒ 3 條探針測試失敗（實際發生過，已改回）。

⚠ 只換外觀：GUI 的 SITL VTOL 是通用 quadplane 動力學，畫成 Hero 不代表它飛 Hero 的參數。
HIL 板若要分開畫，在設定檔寫 `uav_airframes`，例如 `{"1": "pioneer"}`（COM36 是 Pioneer）——注意 GUI SITL 的第一架也是 sysid 1。

## 4. 重建

```
<venv>/python -I tools/build_hero_glb.py fetch                       # 下載 11 個 STEP 到 runs/artifacts/HERO_MODEL/step（驗 sha1）
<venv>/python -I tools/build_hero_glb.py build --check --report runs/artifacts/HERO_MODEL/build_report.json
```

venv 需要 cascadio、trimesh、shapely、numpy（只有建模需要；app 執行期不需要）。OpenCASCADE 讀不了中文路徑 ⇒ STEP 存成英文檔名。
共用的部分（STEP 載入與快取、翼型放樣、槳、GLB 寫出）在 `tools/glb_kit.py`。STEP 三角化快取以 STEP sha＋cascadio 版本＋容差為鍵。
`--check`：另開一個行程、用**全新的空快取**（重新三角化 STEP）再建一次，逐位元組比對（已驗：相同）；工具版本記在報告與 glTF extras。
