## 0. 物理前提(不可協商,所有設計由此推導)

1. **定翼機轉彎半徑** r = v²/(g·tanφ)。φ 為 bank 上限(本機體 65°;受
   STALL_PREVENTION 影響低速時實際上限更低)。
   | v (m/s) | 30 | 60 | 90 | 120 | **148** |
   |---|---|---|---|---|---|
   | r @45° (m) | 92 | 367 | 826 | 1468 | 2233 |
   | r @65° (m) | 43 | 171 | 385 | 685 | **1041** |
2. **穩定跟隨判準(實測)**:追趕速度的轉彎半徑必須小於編隊間距
   —— **r(v_catch) < S**,否則僚機只能繞著 slot 打轉,誤差震盪不收斂
   (實測反例:v_catch=90、S=120 → 誤差 333↔649 m 震盪)。
3. **速度差 = 控制權威**:編隊收斂靠「參考機放慢等 / 僚機加速追」的差速。
   差速 Δv = v_catch − v_wait 必須 ≥ 0.15·v_ref,且 v_wait ≥ 1.3·v_stall、
   v_wait ≥ 機體最低可持平飛速度(噴射機地板實測 ~45-75 m/s,**不是**
   AIRSPEED_MIN 參數,是氣動/推力地板 —— 必須實測認證)。
4. **導引滯後地板**:GUIDED 航點鏈有 ~3-5 s 有效滯後(註冊+迴轉動力學),
   高速下 slot 追蹤誤差存在結構性地板 ≈ v_ref × lag。**唯一解是 slot 前饋**
   (見 §4.4);調參數消不掉。
5. **148 m/s 與「緊」互斥於小間距**:148 m/s 的轉彎半徑 ≥1041 m(65°),
   依判準 2,間距 S 必須 ≥ ~1200 m 才能在此速度穩定跟隨。**需求第 1 條
   「穩定跟隨優先」因此體現為:速度調速器(§4.2)永遠以隊形完整為準繩,
   148 是機體上限、不是巡航承諾。**

## 1. 角色設定

| 角色 | 機號 | 職責 |
|---|---|---|
| **參考機(Reference / Leader)** | UAV1(主)、UAV6(備) | 以 ≥10 Hz 廣播「編隊座標框」:自身位置、航向、地速、爬升率(GeoPose + heartbeat)。執行任務航線 / 盤旋;運行編隊監督器(§3 狀態機 + §4.2 調速器)。 |
| **僚機(Follower)** | UAV2–UAV5 | 永久綁定各自 slot(§1.1),以緊耦合 leader-follower 追蹤 slot:位置經前饋外推後下 GUIDED 航點、速度由閉合律(§4.3)指令。回報 slot 誤差 ≥1 Hz。 |
| **備援參考機(Backup)** | UAV6 | 平時佔 V 尾 slot(slot-6)當一般僚機;偵測參考機心跳逾時(2.5 s)即接任參考 —— **只換「參考框錨點」,不換任何 slot**(§1.2)。 |
| **地面站(GCS)** | — | 下達 guided 起飛、任務航線、盤旋/返航指令;監看;**沒有 slot 重排的 API**(刻意不存在,見驗收 A3)。 |

### 1.1 Slot 永久綁定(需求 3)

- 拓撲:六機雁行 V。slot 以**編隊座標框**(以參考框錨點為原點、框航向為 +X)定義:

  ```
              slot-1(錨點,參考框原點)
        slot-2(左後 rank1)   slot-3(右後 rank1)
      slot-4(左後 rank2)       slot-5(右後 rank2)
              slot-6(正後 V 尾)
  ```
  幾何:rank 間距 S、V 半角 θ=25°、V 尾距 D_tail、**每 slot 專屬高度層**
  ΔH=15 m 階梯(垂直分離,任何水平誤差下都不對撞)。

- 綁定表 `SLOT_MAP = {sysid → slot_id}` 為**編譯期常數**:UAV1→slot-1 …
  UAV6→slot-6。運行期不存在任何寫入路徑;監督器持續稽核「每架機的導引目標
  是否屬於自己的 slot」,目標落入他人 slot 半徑內 = FAULT(§5)。
- 誤差修正、追趕、重連、參考機切換,**一律不得觸發 slot 重排**。

### 1.2 參考框與參考機切換(需求 6)

- Slot 位置一律從**編隊框**計算,不是「相對某台實體機的偏移」。框錨點 =
  當前參考機**自己的 slot 位置**:UAV1 任參考時錨在 slot-1;UAV6 接任時,
  框平移錨到 slot-6 當下位置、航向沿用最後有效框航向。
- 因此切換參考機時:**其他四機的 slot 目標點在空間中連續**(框只是換錨點,
  幾何不變),不會漂向鄰近 slot。這是需求 6 的實作機制,驗收 A6 驗證。

## 2. 控制目標(嚴格優先序,高者絕對優先)

1. **安全分離**:任兩機 3D 距離 ≥ d_safe(= max(0.3·S, 40 m);高度層錯開
   為第一道保險)。
2. **Slot 綁定不變式**:§1.1,任何時刻不得違反。
3. **隊形完整(有界誤差)**:每機 slot 誤差 e_i(t) 全程 ≤ E_crit;穩態
   ≤ E_ss、暫態(轉彎/爬升/接任)≤ E_tr 且 T_rec 內回到 E_ss(數值見 §6)。
4. **任務軌跡**:參考機沿任務航線 / 盤旋。
5. **速度最大化**:在 1–4 全滿足的前提下,盡量貼近 min(148, v_form_ok)
   (§4.2)。**衝突時犧牲順序:先砍速度,再放大間距,絕不解散(需求 7)。**

## 3. 狀態機

```
GROUND_STANDBY ──guided 起飛指令──▶ FORMATION_TAKEOFF ──全員離地+入層──▶ FORM_UP
                                                                           │ worst e ≤ E_form(連續 T_form_ok)
      ┌────────────────────────────────────────────────────────────────────▼
      │                       CRUISE_FORMED
      │           ┌── LEAD_CRUISE(v_ref = v_form_ok)
      │           └── LEAD_WAIT (worst e > H·E_form → v_ref = v_wait)   ←→ 手風琴
      │        │ 盤旋/等待指令                      │ worst e > E_crit 持續 T_crit
      ▼        ▼                                   ▼
   REJOIN   HOLD_FORMED(編隊盤旋)             DEGRADED_KEEP(§5 階梯)
      ▲        │ 恢復巡航指令                      │ 恢復(worst e ≤ E_form)
      └────────┴──────────────────────────────────┘
                                  │ RTL/降落指令
                                  ▼
                        RTL_FORMED ──▶ 依 slot 序列進場解散(僅最後進場段)
```

- **GROUND_STANDBY**:全員地面 disarmed/GUIDED 待命;slot 綁定已生效
  (地面排位即 slot 序)。
- **FORMATION_TAKEOFF(需求 4)**:GCS 一聲 guided 起飛 → 依 slot 序
  交錯滾行(間隔 T_stagger=5 s)。**每機離地爬過 h_gate(15 m)後的第一個
  導引目標就是「自己的 slot 在編隊框中的當下位置」**(框此時錨於 UAV1,
  UAV1 沿起飛航向直線爬升作為框運動)。全程不存在「單機自由飛再集合」:
  任一機任一時刻的目標都只有自己的 slot。
- **FORM_UP**:框沿直線低速前進(v_ref = v_wait),僚機依閉合律入位;
  worst e ≤ E_form 連續 T_form_ok=5 s → CRUISE_FORMED。
- **CRUISE_FORMED**:手風琴雙子態(LEAD_CRUISE/LEAD_WAIT),遲滯係數 H
  防抖(§4.3;實測 H=1.4 會釋放即打回、群速卡死,須 ≥1.8)。
- **HOLD_FORMED(需求 5)**:到高度後的盤旋/等待**不解散**:參考框飛
  跑馬場(racetrack)或圓軌,軌道半徑 R_orb 使**最外側 slot 的路徑速度**
  v_outer = v_orb·(R_orb + S_outer)/R_orb ≤ 0.9·v_catch 且 r(v_outer) < S;
  全員 slot 隨框旋轉,V 形持續可見。
- **DEGRADED_KEEP**:§5 異常階梯;**此狀態的語義是「更慢、更大間距的完整
  V」,不是鬆散跟隨**。
- **REJOIN**:斷鏈/落單機回補**原 slot**專用走廊:從編隊後外側、低於自己
  高度層 10 m 進場,速度先匹配 v_ref 再爬回自己層 → 回自己 slot。全程
  slot_id 不變(驗收 A3)。

## 4. 位置 / 速度約束

### 4.1 幾何 × 速度耦合(核心約束)

- **間距下限**:S ≥ c_r · r(v_catch),安全係數 c_r = 1.15
  (依據:物理前提 2 的實測震盪判準)。
- 兩檔標準工況(可連續縮放,S 由上式即時檢核):

  | 工況 | S | v_ref 巡航 | v_catch | v_wait | 用途 |
  |---|---|---|---|---|---|
  | **TIGHT**(預設,穩定跟隨優先) | 250 m | ≤ 60 | 72 | ≥ max(1.3·v_stall, 機體地板+10%) | 展示緊 V、低速任務 |
  | **FAST** | 1250 m | ≤ 135 | 148 | 同上 | 高速轉場;仍是嚴格 V,只是大 |

  (FAST 檢核:r(148)@65° = 1041 < 1250/1.15 ✗→ 取 S=1250 使 c_r·r=1197<1250 ✓)
- **高度**:每 slot 專屬層(錨層 ± rank×15 m);參考機爬升/下降時各機以
  相同爬升率跟層,層間距不變。
- **轉彎前減速(轉角防甩)**:參考機改變航向 >20° 前,先降至
  v_corner = min(v_ref, sqrt(g·tanφ_max · S / c_out)),c_out =
  (R_ref + S_outer)/R_ref,確保**最外側 slot 需求速度 ≤ v_catch**;
  轉完再加速(依據:實測轉角是誤差尖峰唯一來源)。

### 4.2 速度調速器(需求 1、7 的實作)

參考機速度指令恆為:

```
v_ref_cmd = min( v_mission, v_airframe_max(=148), v_form_ok )
v_form_ok = sqrt( g·tanφ_max · S / c_r )         # 由當前間距反推的隊形可持速度
且 worst_e > H·E_form 時 → v_ref_cmd = v_wait     # 手風琴等待
```

速度永遠是被犧牲的第一順位;調速器輸出全程記錄(驗收 A7 查核)。

### 4.3 僚機閉合律(兩條實測鐵則)

- **斜坡從 err=0 起算**:v_cmd = v_ref + (e/CATCH_R)·(v_catch − v_ref),
  e ≥ CATCH_R 時 = v_catch。**禁止**從 E_form 起算 —— 閉合率在門檻附近
  趨近 0,誤差會漸近卡在門檻上緣、參考機永不釋放(實測:gate 60 → 誤差
  永駐 64-66,群速卡在 v_wait)。
- **成形遲滯 H = 1.8**:成形判定 worst e ≤ E_form;解除判定 worst e >
  H·E_form。依據:巡航時誤差自然膨脹 ~+70 m,H=1.4 實測「一釋放就打回」
  (巡航佔比 5%),H=1.8 → 85%。

### 4.4 Slot 前饋(高速必備)

- 導引航點瞄準「slot 沿框航向外推 t_lead × v_ref 的未來點」,t_lead ≈
  導引鏈滯後(本 stack 實測 3.5 s;新平台須重新認證)。
- **誤差一律對「真 slot」量測**,只有送出的航點用外推點 —— 否則誤差含
  前置量,成形判定被污染(實測踩過:誤差平台恰卡在解除門檻上)。
- 航點指令用 `MAV_CMD_DO_REPOSITION`(COMMAND_INT,GLOBAL_RELATIVE_ALT),
  每 1 s 可重發;**禁用** MISSION_ITEM_INT current=2(實測不吃高度,
  參考機飄到 1000 m)。

### 4.5 通訊與更新率

| 項目 | 要求 |
|---|---|
| 參考框廣播 | ≥ 10 Hz;逾時 2.5 s → 備援接任 |
| 僚機誤差回報 | ≥ 1 Hz;staleness 5 s 即視為缺席(成形判定變 false → 參考機自動放慢,fail-safe 朝「等」偏置) |
| 導引航點刷新 | 1 s 週期 + slot 位移 >6 m 觸發 |

## 5. 異常處理

**總則(需求 7)— 三段保形階梯,依序啟用,絕不跳到「鬆散跟隨」:**

```
第 1 段:減速   v_ref → v_wait(手風琴,自動)
第 2 段:放大間距 S → k·S(k 1.0→2.0 漸增;等比縮放,slot 幾何/綁定不變,
         仍是同一個 V —— 只是大;誤差門檻同步以 k 縮放)
第 3 段:保形盤旋 HOLD_FORMED @ v_wait,原地等收斂(帶 patrol_hold_timeout)
禁止段:解散 / 鬆散跟隨 / slot 重排 —— 不存在此代碼路徑
```

| 異常 | 偵測 | 處置 |
|---|---|---|
| 單機落後 | e_i > CATCH_R | 該機 v_catch 全速追 + 參考機 LEAD_WAIT;持續 T_crit(60 s)未收 → 階梯第 2 段 |
| 僚機斷鏈 | 回報 stale > 5 s | 參考機視為未成形(自動放慢);斷鏈機:航位推測保持原 slot T_dr=10 s → 退到自己高度層 + 後方待命軌道;**重連 → REJOIN 回原 slot,禁止改配**(驗收 A3) |
| 參考機失效 | 心跳逾 2.5 s | UAV6 接任參考(§1.2 框換錨,slot 全部不動);UAV1 復活 → 以僚機身份 REJOIN 回 slot-1,參考權**只由 GCS 指令歸還**(防抖動) |
| 速度權威耗盡(接近機體地板/天花板,差速 < 0.15·v_ref) | 調速器檢核 | 直接進階梯第 2 段(放大間距換取轉彎半徑餘裕)—— 依據:噴射地板實測,差速被夾平時任何調參都無法收斂 |
| GPS 品質劣化(單機) | EKF 方差門檻 | 該機安全泡半徑 ×2、退至層底;不影響他機 slot |
| 兩機距離 < d_safe | 幾何監測 | 低優先機立即垂直讓出(往自己層的遠端),水平指令凍結 2 s;事件記錄(驗收 A1 的 0 容忍項) |

## 6. 驗收標準

門檻定義(隨工況 S 縮放):E_ss = 0.5·S、E_tr = 1.5·S、E_crit = 2.5·S、
E_form = 0.4·S、T_rec = 60 s。全程 ≥1 Hz 記錄每機 slot 誤差、速度指令、
狀態機轉移、slot 目標稽核。

| # | 驗收項 | 通過準則 |
|---|---|---|
| **A1** | **「任一時刻的 slot 誤差不得超過設定門檻」** | 30 分鐘全剖面航次(起飛/巡航/轉彎/爬升/盤旋/返航):所有機 e_i ≤ E_crit 零違規;穩態段 e_i ≤ E_ss 佔比 ≥ 90%;暫態超出 E_tr 後皆於 T_rec 內回到 E_ss。安全分離違規 = 0(一票否決)。 |
| **A2** | **「leader 轉彎、爬升、盤旋時,隊形偏移仍需在容許範圍內」** | 註入 90° 轉彎 ×4、±50 m 階梯爬升 ×2、10 分鐘 HOLD_FORMED:全程 e ≤ E_tr;盤旋段 V 拓撲連續可見(任意時刻機間距離矩陣與 slot 幾何的匹配誤差 ≤ E_tr,rank 序不變)。 |
| **A3** | **「重連後不得改 slot,只能回補原 slot」** | 任選一僚機切斷鏈路 60 s 再恢復 ×3 次(不同機):每次皆經 REJOIN 走廊回到**原 slot_id**;全航次 slot 指派日誌 diff = 空;稽核器零次「目標落入他人 slot」告警。 |
| **A4** | 起飛即編隊(需求 4) | 從 GCS guided 起飛指令起,每機離地後的**第一個**導引目標即為自己 slot(日誌可證);任一時刻無任何機以他人 slot 或自由航點為目標;T_form ≤ 180 s 內達 FORM_UP→CRUISE_FORMED。 |
| **A5** | 盤旋保形(需求 5) | HOLD_FORMED 10 分鐘:worst e ≤ E_tr 全程,無任何機脫離軌道包絡;結束指令後 ≤ 30 s 恢復巡航隊形。 |
| **A6** | 參考機切換不漂移(需求 6) | 飛行中 kill UAV1:UAV6 於 ≤ 2.5 s 接任;其後 30 s 內其餘四機 e ≤ E_tr,且**每機與自己 slot 的距離 < 與任何鄰近 slot 的距離**(逐時刻檢核,零例外);UAV1 復活後 REJOIN 回 slot-1。 |
| **A7** | 保形優先於速度(需求 1、7) | 對任一僚機注入 20% 速度削弱:系統依 §5 階梯反應(日誌可見:先 LEAD_WAIT、再 k 放大),v_ref_cmd 全程 = 調速器輸出,**無任何「解散/鬆散跟隨」轉移**;隊形拓撲全程保持。 |
| **A8** | 速度包絡誠實 | FAST 工況(S=1250):直線段速度可達 ≥ 130 m/s 且 A1 門檻同時滿足;TIGHT 工況(S=250):速度自動被調速器壓在 v_form_ok(≈60-72)以下 —— 驗證「148 是上限不是承諾」。 |
