## 1. 論文方法摘要（主控代理已精讀）

問題：多架同構固定翼 UAV 對多個複雜區域做「動態完全覆蓋路徑規劃」(DCCPP)，目標 min-max 各機路徑長（Eq.17）。

模型：
- UAV 運動學 Eq.(1)：定速 V，最小轉彎半徑 Rmin，爬升角 γ，航向 ψ。
- FOV 模型 Eq.(2)(3)：前視梯形地面投影；由相對高度 h、安裝角 α_m、張角 α_v/α_h 得覆蓋寬 w_i 與前向距離 l_i。論文數值：h=1200 m → w=2200 m；V=230 m/s；Rmin=4000 m（大型軍用固定翼，遠大於本案平台）。
- 地形：DEM 規則網格 + 雙線性內插 Eq.(4)；相對高度限制 h∈[hmin,hmax]。
- 複雜區域：Douglas–Peucker 簡化並凸化；掃描方向 α_k 取多邊形最小寬度方向（轉彎最少）。
- 三類路徑（Fig.4/5）：作業路徑（FOV 有效覆蓋直線段）、進入路徑（初始位置→作業路徑端點）、轉移路徑（作業路徑之間）。每條作業路徑 L_{k,l} 有左右端點 p^L,p^R、兩個方向，三類路徑長度皆「二元」Eq.(10)–(12)。
- 條帶：FOV 上下邊界 Eq.(6)(7)、重疊 w_ovl；端點由條帶與邊界交點與條帶內頂點決定 Eq.(8)(9)。
- 路徑長度矩陣 D_{i,k}（(n+1)×n；第 0 列進入、其餘轉移）與決策矩陣 E_{i,k}（∈{-1,0,1}）Eq.(13)(14)；限制 Eq.(19)–(26)：每條作業路徑恰被一機覆蓋一次、全部覆蓋、不同機不從同一作業路徑進入、相鄰轉移方向相反、作業方向與前段一致。→ MDTSP。

解法（Fig.6）：Dubins 曲線（威脅繞行 Eq.27、弧段離散 Eq.28/29）→ 貪婪配置 Algorithm 1（指標 J_k Eq.30：進入距離/作業路徑數/作業總長/威脅值各 0.25；λ_k=round(n_U·J_k/ΣJ) Eq.31）→ 改良動態規劃 IDP Algorithm 2（逐階段列舉 λ_k 架機各選一條未覆蓋路徑之排列，轉移成本 Eq.33 =（轉移+作業）/已累積距離，取最小；剩餘路徑數<機數時列舉選哪些機）→ 高度規劃 Algorithm 3（等距內插、DEM 內插、曲率修正 Eq.35、受爬升角限制之高度下降 Eq.36、梯度下降平滑 Eq.37/38、共線點刪減 Eq.39）→ 動態事件（UAV 退出、新區域：重初始化、找未覆蓋路徑、重配置＋IDP）。Table 4：IDP 路徑最短、計算 0.06–0.4 s。

論文的限制（本案要突破）：同構；不能懸停／無起降模型；區域整體凸化；成本以距離而非時間；無能量／續航／保留電量；無風；無障礙物（僅圓形威脅）；無返航與備降；無鏈路／空域限制；無感測器需求（LiDAR vs 相機）差異。

## 2. 設計目標：HARVEST（Heterogeneous-VTOL DCCPP）

### 2.1 兩種構型（主控代理已決定，所有代理沿用命名）

| | 構型 A：Pioneer PNP | 構型 B：HERO PNP |
|---|---|---|
| 機型 | 4 升力旋翼 + 後推固定翼（lift-and-cruise 4+1） | 同左 |
| 基準酬載 | 5 kg LiDAR（reference_auw 24.6 kg） | 0.6 kg 測繪相機（reference_auw 6.65 kg） |
| 巡航空速 | 21.5 m/s | 19.0 m/s |
| 規劃轉彎半徑 | 200 m（理論 130 m） | 120 m（理論 75 m） |
| 規劃爬升／下降角 | 3° / 4°（最大 3.5° / 5°） | 同左 |
| 轉換高度 | 起始 60 m AGL、完成 80–100 m AGL | 起始 50、完成 70–90 m AGL |
| 最低固定翼作業高度 | 120 m AGL | 100 m AGL |
| 基準續航／總航程 | 176 min / 242 km | 136 min / 144 km |
| 保留電量 | 30%；可用距離 133–145 km；對稱任務半徑 66–72 km | 30%；79–86 km；39–43 km |
| 角色（設計上的分工） | 遠距、大面積、LiDAR 需求區；長時間佇留 | 近距、小面積／狹窄／凹角區；影像（RGB/GSD）需求區；目標再確認 |

重要推論（所有代理必須遵守）：
1. 兩者都是複合翼：**懸停只用於垂直起降、轉換與緊急狀況，任務中的轉彎一律用固定翼 Dubins（用 turn_radius_planning_m）**。不要設計「懸停定點轉向」的轉移路徑。
2. **3° 爬升 / 4° 下降是極強的限制**：從轉換完成高度爬到任務高度需要很長水平距離（Δh/tan3° ≈ 19·Δh，例如 Δh=100 m → 1.9 km），空間不足時需用半徑 ≥ R_plan 的爬升盤旋（racetrack / orbit）。地形跟隨無法貼合 >3° 的坡；高度剖面必須用「坡度受限包絡」（forward pass 限制爬升率、backward pass 限制下降率，取 max，永不低於地形+淨空）。AGL 因此在陡地形上不是常數 → **條帶寬度要用該條帶上的最小 AGL（保守）計算**才能保證覆蓋。
3. **感測器決定覆蓋寬與速度**：A 為 LiDAR（swath = 2·h·tan(FOV/2)，可設定可用掃描角、點密度需求限制地速）；B 為相機（swath = h·sensor_width/f；GSD = h·pixel_pitch/f；條帶間距 = swath·(1−side_overlap)；地速上限 = footprint_length·(1−forward_overlap)·shutter_rate）。取代論文的前視梯形 FOV（可保留為選項）。每個區域有「感測需求」：lidar / rgb / both / any，配置時必須滿足。
4. **風場**（高度分層 speed/dir）：以風三角求各航段地速（V_g = sqrt(V_a² − (W·sinΔ)²) + W·cosΔ）；作業路徑兩方向時間不同（形成論文「二元」成本的自然來源）；掃描方向以「候選方向的總時間（含風）」評估，最小寬度方向為主要候選；風中轉彎的地面半徑放大要納入轉移路徑；返航逆風要納入能量。
5. **能量模型**：可用電量 Wh（或有效 mAh）為輸入；功率：巡航 P_c（由基準續航/航程與 AUW 推得，AUW 變化以 (AUW/AUW_ref)^1.5 修正）、懸停 P_h（起降）、轉換；30% 保留；battery_monitor_validated=false 時再加保守係數。**每架的計畫必須包含返航段（RTB）**並在任一航點都能以剩餘能量抵達最近備降點（alternate landing site）。
6. **起降走廊**：起飛：垂直爬升至 transition_start_agl → 轉換（逆風）→ transition_complete_agl → 以 3° 爬升至任務高度（必要時盤旋）。降落：以 4° 下降至轉換高度 → 轉換為懸停 → 垂直降落；起降點需 vtol_site_clear_radius 淨空與 obstacle_horizontal_buffer。進入路徑的起始狀態 = 轉換完成點（位置、逆風航向、巡航速度）。
7. **障礙物**：點／線／面 + 高度（電塔、建築、樹、輸電線）；DEM 之外另建 keep-out（水平緩衝 + 垂直淨空）；轉移／進入／返航路徑要繞行（Dubins 繞行如論文 Eq.27，或以緩衝多邊形的可視圖 + Dubins 接合）。
8. **鏈路與空域**：C2 鏈路範圍（km 或覆蓋多邊形）與對稱任務半徑限制所有航點；空域：高度上限（如 120 m AGL 法規值可設定）、禁區多邊形、時間窗；失鏈策略（RTB / 續飛至下一點 / 就近備降）。
9. **氣象門檻**：規劃前 go/no-go 檢查（平均風、陣風、能見度、降雨、溫度）與任務中中止條件。
10. **同構退化**：兩構型參數相同且忽略新增限制時，演算法應退化為論文方法。

### 2.2 演算法層次（對應論文每一層並做異構擴展）

1. 平台／感測器／能量模型（表 1 全部參數化；表 2 全部為輸入）。
2. 區域分解：Douglas–Peucker 簡化；凹多邊形做凸分割（不整體凸化）；各凸胞候選掃描方向（最小寬度方向 ± 風評估）；依構型的條帶寬度（由感測器與該胞的保守 AGL 算出）產生條帶；胞的構型適配度（寬度/面積/感測需求/距離/續航）；寬胞用 w_A 覆蓋後的殘餘窄帶可交給 B（殘帶指派，僅在感測需求允許時）。
3. 任務配置：成本一律為「時間」；目標 min-max 完工時間（含返航）；能量可行性硬限制；鏈路／半徑硬限制；感測需求硬限制；擴充論文 J_k 加入構型適配度；貪婪／拍賣式配置，多架次（同一機可回基地換電後再出）為選項。
4. 路徑優化：異構 MDTSP，沿用三類路徑 + 二元方向 + IDP 逐階段排列列舉，成本為時間（含風），可加 beam width；加入返航段與能量檢查。
5. 三維高度：坡度受限包絡 + 平滑 + 點刪減；A/B 不同任務高度做高度分層；起降走廊與爬升盤旋。
6. 動態重規劃：UAV 退出、新區域、低電量／能量偏差、失鏈、風場更新、目標線索 → 派另一構型近距確認（cue-and-confirm）。
7. 防撞／去衝突：高度分層 + 同高度時間分離 + 起降走廊獨占。
8. 複雜度與即時性；與論文對照。
