# HV-DCCPP 模組契約（Module Contract, v1.1）

套件 `hv_dccpp/`（Python 3.13；numpy、scipy、shapely ≥2.0、matplotlib；不可用網路）。本契約與 `HV-DCCPP_spec.md`（v1.1）配套：規格書定義「算什麼」，本契約定義「介面長什麼樣」，使不同工程師可平行實作各模組後直接接合。所有 dataclass 皆 `slots=True`；輸入型別 `frozen=True`。v1.1 依審查修訂：依賴無環化（新增 `context.py`、`routing.py`、`preflight.py`）、高度一律 ENU $z$、感測器硬體／需求分離、CostCache 四型轉場與索引約定、事件驅動 IDP、§W 全部重算。

## 0 全域約定

| 項目 | 約定 |
|---|---|
| 座標 | 本地 ENU（m），原點 = 主起飛點 `home`；`x`=East、`y`=North、`z`=Up（ENU 之 $u$，已含地球曲率）。輸入／輸出以 WGS84（deg）＋MSL（m）。 |
| 高度基準（D42） | **所有內部函式參數與 dataclass 內部欄位一律 ENU `z_m`**；MSL 只出現在輸入型別（`Site.alt_msl_m`、`WindLayer`、`Airspace.max_msl_m`、`NoFlyZone.z_*_msl_m`、`Obstacle.top_msl_m`）並於解析時以 `GeoFrame.msl_to_enu_z(xy, msl)` 轉換；輸出 `Waypoint` 同時給 `z_m` 與 `alt_msl_m`。ENU $z$ 與 MSL 之差 = $h_0$ + 曲率項（位置相依，50 km 處 196 m），不得手動相減。 |
| 方位 | 航跡方位 `theta`（rad，自北順時針）；$\hat t=(\sin\theta,\cos\theta)$、右法向 $\hat n=(\cos\theta,-\sin\theta)$。介面欄位以 `_deg` 結尾者為度，其餘一律 rad。 |
| 掃描座標 | $u$ 沿 $\hat t$、$v$ 沿右法向 $\hat n$，原點 `Cell.sweep_origin`（胞在 $(\hat t,\hat n)$ 投影之 $(u_{\min},v_{\min})$ 角點）。$\theta=90°$（向東）時 $\hat n$ 指南，$v$ 增加 = 向南，$y=y_0-v$。§W 座標依此。 |
| 風 | `dir_from_deg` 為氣象「來向」；風向量（吹向）$\vec w=-W(\sin\beta,\cos\beta)$。 |
| 單位 | 長度 m、時間 s、速度 m/s、能量 Wh、功率 W、質量 kg、角度 rad。欄位名以 `_m/_s/_mps/_wh/_w/_kg/_rad/_deg` 結尾。 |
| 構型 | `cls: Literal["A","B"]`（A=Pioneer PNP、B=HERO PNP）。 |
| 條帶方向與索引 | `dir ∈ {-1,+1}`：−1 = 自 $p^L$ 向 $p^R$（LR，論文 $e=-1$）；+1 = 自 $p^R$ 向 $p^L$（RL）。`idx = (dir+1)//2`（0 ↔ LR、1 ↔ RL）。**所有陣列第三維的語意 = 該條帶自身的掃描方向**（規格 §8.2）。轉場型 `k = 2*idx_from + idx_to`（0/3 同向 racetrack、1/2 反向）。 |
| 陣列 | numpy `float64`（DEM `float32`）；形狀於簽章以 `(N,k)` 註記。 |
| 不可行 | 成本 `np.inf`；能量檢查回傳結構化結果而非例外；輸入錯誤丟 `MissionInputError`。 |
| 依賴方向（無環，v1.1） | 第 0 層 `geo, platform, dubins, geometry`；第 1 層 `wind`(platform)、`mission`(platform, geo：純資料型別＋`load_mission`)；第 2 層 `context`(geo, platform, mission, wind, geometry：`DecomposeContext`、`MissionContext`、`build_context`)、`routing`(dubins, wind, geometry, geo, mission：`KeepoutSet`、`TangentGraph`、`VisibilityGraph`、`avoid`)；第 3 層 `altitude`(geo, wind, platform, dubins, context, routing) ← `decompose`(geometry, altitude, context) ← `costs`(dubins, wind, geometry, geo, platform, context, routing, altitude)；第 4 層 `preflight`(context, altitude, decompose, costs)、`allocate`(costs, decompose, context) ← `deconflict`(context, wind) ← `planner`(all above) ← `dynamic`(planner)；`sim`, `viz`, `scenario` 只依賴 `context/mission/geo/geometry/platform/planner`。任何模組不得 import 更高層。 |

## 1 `geo.py` — WGS84↔ECEF↔ENU、DEM 網格與雙線性

```python
WGS84_A: float = 6378137.0
WGS84_F: float = 1 / 298.257223563

class GeoFrame:
    """本地 ENU 框架。原點 (lat0, lon0, h0_msl)。"""
    def __init__(self, lat0_deg: float, lon0_deg: float, h0_msl_m: float, geoid_undulation_m: float = 0.0) -> None
    lat0_deg: float; lon0_deg: float; h0_msl_m: float; geoid_undulation_m: float
    origin_ecef: np.ndarray            # (3,)
    rot: np.ndarray                    # (3,3) ECEF→ENU 旋轉（列序 E, N, U）
    def to_enu(self, lat_deg: ArrayLike, lon_deg: ArrayLike, h_msl_m: ArrayLike) -> np.ndarray      # (N,3) [x,y,z] m
    def to_wgs84(self, enu: np.ndarray) -> np.ndarray                                                # (N,3) [lat_deg, lon_deg, h_msl_m]
    def to_enu_xy(self, lat_deg, lon_deg) -> np.ndarray                                              # (N,2)，高程取 0（用於多邊形）
    def enu_z_to_msl(self, xy: np.ndarray, z_enu_m: ArrayLike) -> np.ndarray                         # (N,)：以 to_wgs84 精確轉換（D42）
    def msl_to_enu_z(self, xy: np.ndarray, h_msl_m: ArrayLike) -> np.ndarray                         # (N,)：反向；兩者互逆 <1e-3 m

def geodetic_to_ecef(lat_deg, lon_deg, h_ell_m) -> np.ndarray      # (N,3)
def ecef_to_geodetic(xyz: np.ndarray) -> np.ndarray                 # (N,3) Bowring 閉式 + 1 次牛頓；<1 mm

@dataclass(frozen=True, slots=True)
class DemGrid:                         # 表 2「地形模型」
    lat0_deg: float; lon0_deg: float   # 左下角節點
    dlat_deg: float; dlon_deg: float
    z_msl: np.ndarray                  # (rows, cols) float32, m MSL；rows 沿 lat、cols 沿 lon
    is_dsm: bool = False
    vertical_datum: Literal["msl", "ellipsoid"] = "msl"
    geoid_undulation_m: float = 0.0
    sigma_z_m: float | None = None     # DEM 高程誤差（1σ），進入 terrain_clearance 下限

class TerrainGrid:
    """ENU 規則網格（步長 step_m），雙線性內插（論文 Eq.4）。含障礙燒入。"""
    x0_m: float; y0_m: float; step_m: float; nx: int; ny: int
    z: np.ndarray                      # (ny, nx) float32，ENU z（已含曲率下垂）
    z_raw: np.ndarray                  # 燒入前
    @classmethod
    def from_dem(cls, dem: DemGrid, frame: GeoFrame, step_m: float, bounds_enu: tuple[float, float, float, float]) -> "TerrainGrid"
    def z_at(self, xy: np.ndarray) -> np.ndarray                     # (N,2)→(N,) m；範圍外回 nan
    def slope_at(self, xy: np.ndarray) -> np.ndarray                 # (N,) rad（梯度模）
    def corridor_max(self, path_xy: np.ndarray, theta_rad: np.ndarray, half_width_m: np.ndarray | float, dv_m: float, offset_m: float = 0.0) -> np.ndarray   # (N,)：沿右法向 n̂(θ) 於 [offset−hw, offset+hw] 內最高 z（取樣 Δv=dv_m）
    def corridor_min(self, path_xy, theta_rad, half_width_m, dv_m, offset_m: float = 0.0) -> np.ndarray
    def max_in_polygon(self, poly: shapely.Polygon) -> float
    def min_in_polygon(self, poly: shapely.Polygon) -> float
    def burn(self, polys: list[shapely.Polygon], tops_z: list[float]) -> None   # z = max(z, top) 於多邊形內（已含水平緩衝）
    def bounds(self) -> tuple[float, float, float, float]
```

不變量：`to_wgs84(to_enu(p)) == p`（<1e-3 m）；50 km 處平地 `to_enu` 之 z ≈ −196 m（曲率）；`msl_to_enu_z(xy, enu_z_to_msl(xy, z)) == z`（<1e-3 m）；`corridor_max(path, 0) == z_at(path)`；`burn` 單調不減。測試：`test_geo.py`。
