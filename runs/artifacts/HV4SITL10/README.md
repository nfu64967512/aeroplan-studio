## ⚠⚠⚠ 第一次起飛失敗：埠被 WSL 搶走

第一次跑 `fly` 在 `tcp:127.0.0.1:5760` 等 90 s 拿不到心跳而中止。診斷過程：

1. 手動跑同一條命令列（同一份 `A1.param`）→ ArduPlane **正常起來**並 bind 5760。
   ⇒ 不是二進位檔或參數檔的問題。
2. 查誰在聽那四個埠 → **同一個 PID 30944 同時持有 5760/5770/5780/5790**，
   而 `Get-Process ArduPlane` 是 **0**。
3. 那個 PID 是 **`wslrelay.exe`** —— WSL2 的埠轉發。
   **另一個 session 的 WSL SITL 群**佔著標準 ArduPilot SITL 埠段。

⇒ 我們的 ArduPlane 起得來，但 client 連到的是**別人的載具**，
症狀長得像「我們的 SITL 壞了」。

**修法**：`scripts/hv_sitl_run.py` 新增 `HV_INSTANCE_OFFSET`（預設 0）。
`HV_INSTANCE_OFFSET=10` ⇒ instance 10..13 ⇒ 埠 5860..5890，兩邊互不干擾。
本趟即以此跑成。⚠ **不可以**去砍 `wslrelay.exe`，那會打斷另一個 session 正在跑的東西。
