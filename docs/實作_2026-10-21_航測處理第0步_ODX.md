| 設定 | `D:\ODX\nodeodx-local.json`：埠 3000（套件預設是 "auto" 亂數埠）、一次一個任務、完成任務保留 7 天（方便接回）、沒有權杖 |
| 啟動 | 雙擊 `D:\ODX\start_nodeodx.cmd`（日誌在 `D:\ODX\logs`）。開機不會自動啟動、不是 Windows 服務 |
| 測試資料 | `D:\ODX\datasets\odm_data_aukerman-master`（77 張、CC0） |

⚠ 要知道的三件事：
1. **NodeODX 對所有網路介面開 3000 埠**，它沒有「只聽本機」的選項；`authorizedIps` **只有設權杖時才生效**（NodeODX `libs/auth/factory.js`），所以設定檔裡已拿掉。
   現在擋住其他電腦的是 Windows 防火牆：`nodeodx.exe` 在「公用」網路的連入規則是封鎖，而本機網路是公用。
2. `start_nodeodx.cmd` 第二行的註解寫「Localhost only (authorizedIps)」**是錯的**（我改它時被安全檢查擋下，沒再動）；請自己刪掉那行。
3. Claude Code 的執行環境設了 `NoDefaultCurrentDirectoryInExePath=1`，從那裡啟動的 NodeODX 找不到 ODX 的 `winrun.bat`；
   你自己雙擊啟動不受影響（這個變數不在你的使用者或系統環境變數裡）。這次是只對 NodeODX 那一個行程清掉它。

## 2. 程式改了什麼

| 項目 | 做法 |
|---|---|
| 分段上傳 | `survey/odm_client.py`：`/task/new/init`（**multipart**＋本機產生的 `set-uuid`）→ 依檔數與位元組上限分批 `/task/new/upload/{uuid}`（從磁碟串流）→ `/task/new/commit/{uuid}`。重送只在安全時做（NodeODX 同名檔會被改名成 `_` 版本 ⇒ 盲目重送會產生重複影像）；提交前取消或失敗會清理；記憶體上限有測試 |
| 參數真的生效 | 提交後讀 `/task/{uuid}/info` 的 options 逐項對照送出的（被丟掉或改值就取消並報錯），再解析 ODX 主控台的實際參數列對照；`maxImages` 連 .txt 一起算 |
| `--force-gps` | 有 gcp_list 時**必選**（沒有預設）：「照片 GPS 也參與平差」或「只用 GCP」；沒有 GCP 時不適用、不送。送與不送、理由都寫進任務紀錄 |
| `--max-concurrency` | 選填；空白 ＝ 不送（引擎預設＝全部核心），有填就送；欄位下寫 128 GB／2,500 張建議 10–12 |
| geo.txt 精度欄 | 第 8 欄改寫**單軸 σ ＝ 二維 HRMS／√2**（ODX 把它當 x、y 各自的 σ）；換算寫進 qa.json 與任務紀錄；有每張精度時不送 `--gps-accuracy`（會蓋掉每張的值） |
| 引擎版本 | 送出前 `GET /info`（引擎、版本、記憶體、核心數）寫進 `odm/submission.json` |
| 品質報告 | 下載解壓後讀 `odm_report/stats.json`（重建張數、重投影誤差、照片位置對解算位置、3D 誤差、GCP 誤差、GSD、處理時間）→ `odm/quality_summary.json`、結果分頁表格；`report.pdf`／`shots.geojson` 列路徑；缺檔或壞檔大聲警告 |
| 任務接回 | 「接回既有任務…」選輸出資料夾 ⇒ 依 `odm/submission.json` 的 uuid 接著輪詢、下載、讀品質報告；規劃器當掉、對話框關掉都接得回；`取消遠端任務` 按鈕 |
| 「完成」不是證據 | **（我實測後加的）** 節點回報完成但成果沒有正射 ⇒ 記成失敗（`empty_result`）並附主控台最後幾行 |
| 權杖 | 只在連線時用，不寫進任何檔案、紀錄、log、錯誤訊息（含短權杖的情況） |
| 計畫快照 | 新模組 `survey/plan_snapshot.py`：建圖任務**寫入成功（飛控 ACK）**才存 `runs/survey/…`（`AEROPLAN_PLAN_SNAPSHOT_DIR` 可改）；內容決定性、有 sha256 防竄改、不含機密；對話框可選「載入計畫快照」取代目前規劃器的作業區與 GCP 區塊，並記錄用的是哪個來源。鏈路中斷、HIL 斷線、另開寫入時，等待中的那架標成寫入結果不明 |
| 主視窗 | 對話框已開著就叫回同一個（不再開第二個）；關主視窗時詢問處理中的工作（遠端 ODM 任務繼續、之後可接回），在其他「是否儲存」問題之後才真的停 |
