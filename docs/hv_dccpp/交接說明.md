## 1. 這個資料夾是什麼

`vtol演篹法/` 內是一套完整的 **HARVEST**（Heterogeneous-VTOL Dynamic Complete Coverage Path Planning，異構 VTOL 動態完全覆蓋路徑規劃）：

- **演算法設計**：以 Wang et al. 2025（*Defence Technology* 47:197–215，DCCPP）為基礎，擴展成**兩種構型同時作業**的群飛偵查覆蓋路徑規劃。
- **參考實作**：Python 函式庫 `hv_dccpp/`，24 個模組、約 30,800 行，809 項測試全數通過。
- **輸出**：每架的 4D 航點（經緯度、高度、時刻、模式、感測器開關），可直接匯出成 ArduPilot QuadPlane 任務檔並以 MAVLink 上傳。

兩個目標平台（數值取自 `docs/平台參數表.md`，**不得更改**）：

| | 構型 A：Pioneer PNP | 構型 B：HERO PNP |
|---|---|---|
| 機型 | 4 升力旋翼 + 後推固定翼（lift-and-cruise 4+1） | 同左 |
| 酬載 | 5 kg LiDAR | 0.6 kg 測繪相機 |
| 巡航空速 | 21.5 m/s | 19.0 m/s |
| 規劃轉彎半徑 | 200 m | 120 m |
| 規劃爬升／下降角 | 3° / 4° | 3° / 4° |
| 基準續航／航程 | 176 min / 242 km | 136 min / 144 km |
| 保留電量 | 30% | 30% |

## 2. 五分鐘確認環境沒問題

在另一台電腦上：

```bash
cd <本資料夾>
python -m pip install -e .            # Python >= 3.11（開發環境 3.13）
python -m pytest tests -q             # 應為 809 passed，約 110 s
python examples/run_mini.py           # 應在約 4 s 內結束並印出 validation PASS
```

`run_mini.py` 跑完會在 `figures/mini/` 產生 5 張圖、在 `figures/ardupilot/mini/` 產生 A1/B1 的 `.waypoints`、`.param`、rally、fence、`.plan`。若這三步都過，環境就沒問題。

相依套件：`numpy`、`scipy`、`shapely>=2`、`matplotlib`（繪圖）、`pymavlink`（MAVLink 上傳，可選）、`paho-mqtt`（MQTT 橋接，可選）。

## 6. 在另一台電腦接入 AEROPLAN Studio

完整步驟見 `docs/AEROPLAN_接入手冊.md`。這裡只講骨架：

1. 把本資料夾複製過去，在 AEROPLAN 的虛擬環境裡 `pip install -e <本資料夾>`。
2. AEROPLAN 的相依套件（numpy、scipy、shapely、matplotlib、pymavlink）已涵蓋 hv_dccpp 所需，不需額外安裝。
3. 主接縫是 `mission/swarm_coordinator.py` 的 `plan_coverage_dccpp`。`hv_dccpp.integration.aeroplan_adapter.HvDccppCoordinator` 的簽章與回傳的六鍵字典與它完全一致，所以地圖顯示、禁飛區重繞、防撞、航點匯出、SITL 上傳、spawn home 推導等下游全部不用改。
4. **必做**：把規劃移到工作執行緒。AEROPLAN 現在是同步跑在 GUI 執行緒，大情境會讓視窗顯示「沒有回應」。手冊第 7 節有可直接貼上的 `QThread` worker。
5. 打包成 exe 時要在 `aeroplan_studio.spec` 的 `hiddenimports` 加入 `hv_dccpp`。

接入時要注意 AEROPLAN 側的三個既有限制（手冊第 1 節有完整說明）：`fov_width` 欄位寫了卻從未被讀、全隊共用單一轉彎半徑與單一高度、`'vtol'` 會被靜默降級成多旋翼。換成 hv_dccpp 後這些都由新引擎接手。

## 8. 給接手者的提醒

- `docs/平台參數表.md` 的數值是使用者提供的權威來源，**任何情況下都不要修改**。標示「待填入／待任務定義／暫定」的項目是可設定參數，預設值都帶有 provisional 警告。
- 模組契約（`docs/reference/模組契約_v1.1.md`）定義了所有函式簽章與不變量。若必須偏離，請在 `hv_dccpp/CONTRACT_DEVIATIONS.md` **檔尾追加**一節說明，不要改寫既有段落。
- 文件與註解用繁體中文（台灣用語），專有名詞附英文。
- 每次工作結束前，在 `docs/進度紀錄.md` 追加一節：日期時間、完成事項、測試數字、示例執行結果、未完成事項與下一步。這是唯一的狀態來源。
