### 欄位定義(⚠️ 帶方向)

* **所需俯角** = `atan(高度 / 到目標水平距)`,**正值**,指「若走直線打到目標,航跡必須向下傾多少度」。

* **徑向速率**:**正 = 正在遠離目標(外擺)**,負 = 正在逼近(內衝)。

* **釘 vmin %**:速度指令 = vmin 的比例。**100% = 同步迴路在俯衝段完全沒有權限**(基準批四架次皆是)。

* **頂到上限 %**:速度指令 = dive_speed 的比例。⚠️ 與上一欄意義**相反** —— 一個是權限歸零、一個是權限用滿。混看會把結論讀反。

* **俯衝耗時** = 從 `mode` 轉入 `dive` 到首次 AGL < 3 m。

# ⚠️ 本輪最重要的三個發現(請據此回答,不要重述)

## 發現一:機體是「遲到」不是「早到」,而 ITCG 只能延後

共同命中時刻 `t_d = max_j(t_go_j) + 2 s`。設定當下每架都早到 ≥ 2 s。
但**被空間閘門擋住的那架繼續等**:時鐘在走而它的 t_go 幾乎不動
⇒ 時間誤差一路掉成負的。

實測(RQC,放行瞬間的 `(t_d − t) − t_go`):

| | e_s(秒) |
|---|---|
| RQC1 UAV1 | −0.19 |
| RQC1 UAV2 | **−41.27** |
| RQC3 UAV1 | −0.07 |
| RQC3 UAV2 | −0.29 |

而 `de_t/dt = −V(1 − cos σ) ≤ 0` ⇒ 這類律**只能加長航程**。
⇒ **ITCG 拿到的是一個它結構上無法解決的問題。**

## 發現二:文獻的等速誤差形式在我們的剖面上完全失效

`e_t = V·(t_d − t) − R` 假設**等速**。我們的俯衝是**重力加速**:
放行瞬間實測瞬時地速 **142.7 m/s**,而預測器算出的隱含平均速度是 **208 m/s**。
⇒ 用瞬時速度乘剩餘時間必然構不到斜距 ⇒ e_t 恆為負 ⇒ 整條律一次都沒出力。

RQC 四趟八架的 `itcg_accel` 非零樣本 = **0**,而契約檢查全部顯示 OK。
