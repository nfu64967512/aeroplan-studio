# 實作：SITL 控制頁「群控／單機」兩種模式 — 2026-10-22

使用者：「servo output 跟 message 應該是我選哪一台飛機就列出哪一台的，所以 SITL 操作面板應該要有兩個模式：一種是群控，一種是我需要單獨看某一台飛機的詳細資訊的版本。」
本機 vtol 分支、**未 commit**。延續 `docs/實作_2026-10-17_SITL控制頁精簡與攻擊功能下架.md` 的版面。

## 1. 怎麼用

SITL 分頁「HUD / Servo」最上面 LINK 標題列右側多了兩顆鈕：**群控**（預設）與 **單機**。模式只存在記憶體（程式其他地方沒有用 QSettings 存介面狀態），每次啟動回到群控。

| | 群控 | 單機 |
|---|---|---|
| 版面 | 每台一張卡片（同以前）＋飛行指令＋任務＋日誌 | 機號列（UAV1／UAV2…）→ 該機大 HUD、遙測多久前（3 s 轉琥珀、10 s 紅色 STALE）→ 飛行指令 → 訊息 → 任務 → 日誌 → SERVO → 詳細數值表 → 參數 |
| 訊息 | **合併清單**，每行標 `[UAVn]` 與來源 `[FC]／[GCS]／[LOG]／[條帶]`；非機體來源（MAVROS 等）標 `[EXT n]` | **只有這一台**的訊息（切換時立刻顯示該機歷史）＋本機地面站訊息；其他機的斷線與嚴重訊息也會出現並標 `[UAVn]` |
| SERVO OUTPUT | 收起 | **這一台**的 16 通道 PWM 與 SERVOn_FUNCTION／MIN／TRIM／MAX／REVERSED；參數依機快取，切換時先清空，還沒讀到的顯示「—」 |
| 指令對象 | 同以前：點卡片＝單獨那台，「全部」＝全部 | **只送這一台**（顯示「UAVn（單機模式）」，「全部」停用）；沒選機時拒絕並說明 |

- 單機模式下其他機有嚴重訊息（severity ≤ 3）時，那台的機號鈕變紅並顯示未讀數（`UAV3 ●1`），選它就清掉。
- 正在看的那台斷線時顯示「UAVn 已斷線，請重新選擇」，**不會自己換到別台**（避免指令對象被靜默換掉），訊息歷史保留。
- 單機模式下任務上傳只寫選中的那台（逐機路徑照全隊配對算，那台拿到的路徑與群控上傳相同）；整隊才有意義的動作（建圖整隊上傳、依時程放行）會拒絕並說明；下載全部 .bin、寫入每架匯入只對選中的那台。
- 「Command」分頁上方的機號列與單機的選機**雙向同步**；從 Command 分頁換機時單機訊息區會記一行「單機對象改為 UAVn（來自 Command 分頁）」。群控的指令對象不會被 Command 分頁改到。Command 分頁隱藏時先不同步（它一換機就會向飛控要全部參數），顯示時再套用。

## 2. 資料怎麼帶上機號

- `mission/sitl_link.py`：新信號 `status_text_sysid(sysid, severity, text, kind)`、`servo_param_sysid(sysid, ch, key, value)`，與舊信號並存；
  40 幾個既有 emit 點不動，用一個轉送槽＋每執行緒標記帶上真正的來源機號（兩執行緒 400 則併發測試 0 則標錯）。
  只有確認是機體（或鏈路標籤）且元件是自駕儀的 STATUSTEXT 才標 `fc`，其他標 `ext`。
- 參數回報洪水：每台每秒最多逐筆列 10 行，其餘合併成「（UAVn 參數回報 N 筆未逐筆列出）」；與飛控訊息分開存，整份參數下載不會把飛控訊息擠出歷史。
- `ui/main_window.py` 只接新信號（AST 鎖住不會重複接舊的）；條帶監測警報帶機號；HIL 全部斷線會清 HUD 卡片。
- 新檔 `ui/widgets/sitl_messages.py`：依機與全隊的環形緩衝。

## 4. 限制／沒做

- Command 分頁的 Flights 紀錄仍依連線標記，它的篩選不跟選機。
- 解鎖、任務上傳這類阻塞交易期間到達的 STATUSTEXT 仍會被丟掉（既有行為）。
- 真實機號與連線標籤不同的飛機仍然沒有卡片、不能選（既有限制）。
- 確認對話框在單機模式仍寫「（單獨）」。
- 只在離屏與單元測試驗過，**還沒在真的多機 SITL 下操作過**。
