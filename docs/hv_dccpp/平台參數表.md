## 表 2：任務輸入

| 任務輸入      | 格式／單位                       | 為何必要                         |
| --------- | --------------------------- | ---------------------------- |
| 起飛點與備降點   | WGS84 經緯度、MSL／AGL           | 決定起降走廊、返航與故障轉降可行性            |
| 任務區域      | Polygon／GeoJSON             | Coverage path、geofence 與條帶產生 |
| 地形模型      | DEM／DSM，高程 m MSL            | 坡度、地形跟隨與 AGL 安全淨空            |
| 障礙物資料     | 點／線／面與高度                    | 電塔、建築、樹、輸電線無法只依 DEM 處理       |
| 風場        | 高度分層的風速 m/s、風向 °            | 修正地速、耗時、逆風返航與轉彎半徑            |
| 當架次 AUW   | kg                          | 反映酬載、電池與配件造成的爬升／續航差異         |
| 可用電量      | Wh 或有效容量 mAh                | 不應只依標稱電池容量                   |
| 酬載任務需求    | LiDAR FOV／相機焦距、GSD、重疊率、快門頻率 | 決定航高、速度、條帶間距與端點延伸            |
| C2 資料鏈路覆蓋 | km 或 coverage polygon       | 限制安全任務半徑與失鏈策略                |
| 空域與法規限制   | 高度、禁區、時間窗                   | 直接約束可行航跡                     |
| 作業氣象門檻    | 平均風、陣風、能見度、降雨、溫度            | 決定是否放飛與任務中止條件                |

使用者原話：「這兩大項也要考慮進去 這兩台是主要設計的VTOL平台」
